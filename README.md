# Национальная система стандартизации

Подробное интерактивное приложение для теоретического занятия в СПО. Продолжительность рекомендуемого занятия — 90 минут. Язык — русский. Содержание проверено 16 октября 2026 года.

## Запуск

Откройте `index.html` в браузере. Установка, сервер, Node.js и регистрация для работы приложения не требуются. Шрифт Montserrat включён в комплект. Сетевые запросы для работы теории и упражнений не нужны; внешние нормативные источники открываются при наличии интернета.

Для удобного открытия одним файлом используется версия `Стандартизация_интерактивное_занятие.html` в корне репозитория. Она содержит те же материалы, стили, сценарии и встроенный шрифт.

## Содержание и интерактив

1. **Органы и службы по стандартизации.** Национальная система, виды документов, функции Минпромторга, Росстандарта, ТК/ПТК, разработчика и службы организации. Интерактивная карта участников.
2. **Порядок разработки стандартов.** Планирование, первая редакция, публичное обсуждение, доработка, экспертиза, утверждение, опубликование и актуализация. Кликабельная схема и тренажёр порядка семи этапов.
3. **Государственные контроль и надзор.** Обязательные требования, добровольное применение, договорные условия, публичное заявление, полномочия органов и доказательства. Три ситуации для самостоятельного решения.
4. **Маркировка продукции.** Обозначение стандарта, знак национальной системы стандартизации, знаки добровольной сертификации и EAC. Сравнение правового назначения и три ситуации с обратной связью.
5. **Нормоконтроль.** Область применения, комплектность, реквизиты, ссылки, согласованность, полезные замечания. Проверка шести фрагментов документации по явно указанным учебным условиям.

Дополнительно: двадцать вопросов итоговой самопроверки с разбором, словарь из шестнадцати терминов с поиском, рабочая тетрадь, экспорт конспекта и результата в TXT, нормативные источники, режим преподавателя с методическими рекомендациями, увеличение текста и режим демонстрации.

## Проведение занятия

| Время | Работа |
|---|---|
| 0–5 минут | Актуализация: где студенты встречали обозначение ГОСТ, EAC и техническую документацию |
| 5–20 минут | Органы и службы: объяснение и распределение полномочий |
| 20–35 минут | Разработка: схема, обсуждение и сборка этапов |
| 35–50 минут | Контроль и надзор: три основания применения требований |
| 50–65 минут | Маркировка: сравнительная таблица и кейсы |
| 65–80 минут | Нормоконтроль: проверка документа и формулирование замечания |
| 80–90 минут | Итоговая самопроверка и рефлексия |

Переключатель **«Режим преподавателя»** показывает рекомендации в тематических разделах и сценарий на стартовой странице. **«На экран»** скрывает боковую навигацию и увеличивает текст; повторное нажатие возвращает меню. **«Аа +»** увеличивает основной текст. **«Печать»** печатает открытый раздел с раскрытыми пояснениями. Полная теория отдельно приведена в `THEORY.md`.

Alt + → / Alt + ← переключают разделы, если курсор не находится в поле ввода. Тренажёр этапов управляется кнопками ↑ и ↓. Все основные действия доступны с клавиатуры. На телефоне меню открывается кнопкой ☰.

## Результаты и данные

Один балл за правильный ответ. Шкала для учебной самопроверки: 18–20 баллов — «5», 14–17 — «4», 10–13 — «3», 0–9 — «2». До завершения теста правильные варианты не выделяются. Все вопросы требуют ответа. После завершения доступны результат по темам, объяснения и экспорт отчёта.

Отметки изучения, ответы тренажёров, записи и до десяти последних попыток хранятся в `localStorage` текущего браузера. ФИО и группа необязательны и не передаются на сервер. В приватном режиме и при запрете хранения сохранение может не работать. На общем компьютере скачайте записи и очистите данные через «Мой конспект».

У приложения нет серверной базы, закрытого кабинета преподавателя и автоматической отправки оценок. Режим преподавателя — методический. Для сбора результатов студенты передают скачанный отчёт. Исходные ответы открыты: тест не предназначен для защищённой аттестации.

## Публикация на GitHub Pages

В этом репозитории используется **Deploy from a branch → main → /(root)**. После сохранения изменений GitHub автоматически обновляет сайт. Фактический адрес опубликованного занятия показан в **Settings → Pages** и в окружении **github-pages**.

Для открытия занятия студентам не нужен работающий Codespace. GitHub Pages обслуживает статические файлы отдельно от среды разработки. Внешние страницы с нормативными документами могут иметь собственные ограничения доступа.

Для публикации копии загрузите все файлы вместе с папкой `assets` в свой публичный репозиторий, затем в **Settings → Pages** выберите источник **Deploy from a branch**, ветку **main** и папку **/(root)**.

## Нормативная актуальность

Все ссылки и пояснения приведены внутри приложения, раздел «Нормативные источники», и в `THEORY.md`.

Особое внимание: ГОСТ Р 2.111-2026 утверждён 27.08.2026, дата введения — 01.10.2027 с правом досрочного применения. В учебнике это не представлено как уже наступившая всеобщая обязанность. Нормоконтроль по ЕСКД не объявляется универсальным правилом для любой студенческой или программной документации.

Задания и ситуации условные, с явными учебными предпосылками. Организации и документы реальные. Материал изложен своими словами и не является официальным изданием стандартов.

## Файлы

- `index.html` — оболочка приложения.
- `content.js` — подробная теория, интерактивные данные и вопросы.
- `app.js` — навигация, сохранение, задания, оценивание и экспорт.
- `style.css` — адаптивный интерфейс, печать и режим демонстрации.
- `assets/Montserrat.ttf` и `assets/OFL.txt` — шрифт и его лицензия.
- `THEORY.md` — полный текст для чтения без JavaScript.

## Проверка

Проверены синтаксис JavaScript, наличие файлов, целостность данных, маршруты интерфейса, границы шкалы оценок, незавершённая попытка, восстановление состояния и содержимое отчёта. Визуальная проверка в браузере не проводилась. Работоспособность опубликованного URL нужно подтвердить после фактического развёртывания.
